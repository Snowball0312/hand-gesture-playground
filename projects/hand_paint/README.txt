手势作画 · 说明
================================================================

运行：双击根目录“启动手势作画.bat”，或在根目录执行
    py -3.12 projects/hand_paint/paint_app.py

退出：窗口里按 ESC；按 c 清空当前所有笔画。

手势定义
----------------------------------------------------------------
只伸食指、其余手指弯曲  → 画笔，指尖连续作画
拇指 + 食指捏合          → 选中离指尖最近的一笔，拖动平移
张开手掌                 → 光标下的笔画爆炸成粒子后消失
其他姿态（握拳、两指等） → 悬停，只显示光标

画面
----------------------------------------------------------------
深色画布，笔画叠在上面；黑色投影保证笔画清晰，再叠淡青辉光和青白色笔芯。不显示摄像头画面。
光标颜色随模式变化：绿=画笔，黄=拖动，红=爆炸擦除，灰=悬停。
左上角显示模式、笔画数、FPS 和单次识别耗时。

文件分工
----------------------------------------------------------------
paint_app.py      主程序：状态机、手势防抖、粒子叠加、60FPS 渲染循环
paint_detector.py 检测器：gesture_core.HandTracker 的薄封装（640x480 / 镜像 / 60fps 请求）
paint_rules.py    手势语义：画笔/捏合/张掌擦除/悬停 的映射，几何判定来自 gesture_core
strokes.py        矢量笔画数据、命中测试、拖动与删除、渲染
particles.py      爆炸粒子效果

可调参数（paint_app.py 顶部）
----------------------------------------------------------------
HIT_RADIUS=34     捏合选中的命中半径
ERASE_RADIUS=42   张掌爆炸擦除的命中半径
EMA_ALPHA=0.5     指尖平滑系数，抖就调小，延迟就调大
MODE_HOLD=2       手势防抖帧数，误触发多就调大
TARGET_FPS=60     渲染帧率上限

说明
----------------------------------------------------------------
· 笔画以矢量点序列保存在内存，不存盘、不输出图片。
· 识别线程约 30FPS 节流运行，主线程渲染 60FPS，避免检测抢占画面。
· 识别统一走 gesture_core；本目录只保留“作画语义”，不重复实现检测逻辑。
