立体圣诞树 · 手势交互
========================

双手摄像头前操作，不需要鼠标。
左右手分工和镜头小窗里看到的一致：画面左侧是你的左手。

手势
  左手捏合拖动    抓住树转着看（松手会顺着手势滑一小段再停）
  左手握拳 / 张开  拉远 / 拉近（手停在中位就不动，越张开越近）
  右手食指        屏幕上有个圆环光标，指着哪个礼物哪个亮
                  压在礼物上时圆环变金色、外圈放大一圈，就是"可以捏了"
  右手捏合        礼物飞到屏幕中心，其余画面虚化
  聚焦时右手张开  打开礼物：物件弹出 + 粒子特效
  聚焦/打开时再捏合  回到圣诞树

快捷键
  C      显示 / 隐藏右下角镜头小窗（录屏想干净就关掉）
  F      全屏
  ESC    退出
  鼠标拖动 / 滚轮    没有摄像头时也能转视角、缩放
                    上下拖动是镜头抬高/压低（可一路俯视到树顶，雪地始终水平）
  1-6               直接选中某个礼物（调试用）
  空格 / O          模拟"捏合" / "打开"（调试用）

六个礼物（打开后都是一张会缓慢自转的 2D 人物卡，背面自动镜像）
  1 号盒 · 手势黄人   2 号盒 · 大笑黄人（开盒时有笑声）
  3 号盒 · 天使黄人   4 号盒 · 跳跃黄人
  5 号盒 · 捧心黄人   6 号盒 · 功夫黄人

声音
  只有 2 号盒（大笑）有音效：捏合打开的那一刻播 assets/laugh_open.wav，
  选中/聚焦时不出声；再捏合退回时立刻掐掉，不等它放完。
  音效在启动时就预加载（解码约 0.3s），开盒那一下不再有加载空等。
  原始 laugh.wav 开头有 1.675s 纯静音，tools_trim_audio.py 把它切掉并加 8ms
  淡入后另存为 laugh_open.wav，现在开盒 0.03s 就听到笑声。
  想让它比开盒稍微晚一点响，改 main.py 里的 AUDIO_DELAY_S（默认 0）。

树顶星
  实体五角星（前后各一道尖脊、逐面高光），插在树干尖上，
  转树的时候跟着一起转，不是贴一张永久正对镜头的图。

依赖
  PyQt6  PyOpenGL  opencv-python  mediapipe  numpy
  手部模型：仓库根目录 assets/hand_landmarker.task
  （缺失时先在根目录跑一次 py -3.12 tools/fetch_assets.py）

运行
  双击根目录「启动圣诞树.bat」

素材
  assets/gift_char_1..5.png 由 tools_import_chars.py 从用户提供的五张抠图
  角色统一导入（裁掉透明边、按同一可见高度缩放、顺手去掉了抠图留下的白边）。
  assets/laugh.wav 是 2 号盒的笑声，同样由那个脚本复制过来（原样，含开头静音）。
  assets/laugh_open.wav 是 tools_trim_audio.py 切掉开头静音、加淡入后的成品，
  程序实际播的是它；换素材后重跑一次那个脚本即可。
  assets/gift5_character.png 是最早那张捧心人物，由 tools_cutout.py 从原图抠出，
  严格保留人物原样，只去掉了白色背景。
