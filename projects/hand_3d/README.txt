双手 3D 地球 · 说明
================================================================

运行：双击根目录“启动双手地球.bat”。
一打开就是中国正对镜头、北方朝上的姿态，北京上立着一枚红色大头针。

手势（地球模式）
----------------------------------------------------------------
屏幕左侧的手：
  拇指 + 食指捏合 = 按住，移动手拖动地球旋转；松开即停（带一点惯性）。

屏幕右侧的手：
  保持张开程度：越张开，镜头越靠近地球；握拳越紧，镜头越拉远。
  两只手可以同时操作，一边转一边缩放。

双手同时捏合（约 0.5 秒）= 进入全屏中国地图（按 M 键等价）。

模式链：地球 → 中国平面 → 省 → 市
----------------------------------------------------------------
中国地图现在是 2D 矢量地图（map_data / map_view / roam，代码与数据都在本目录），
作为子窗口叠在地球上，约 260ms 交叉淡入淡出；
地图完全不透明后地球暂停渲染，切回地球时自动恢复。
旧版“贴在球面上的中国地图贴片”代码仍保留在 GLWidget 中，
但主窗口已改走 2D 地图（GLWidget 单独使用时仍可复现旧行为）。

地图内的手势：
  屏幕右侧的手：食指移动 = 光标；悬停某省 + 捏合保持 0.5 秒 = 进入该省。
  屏幕左侧的手：捏合横拖 = 平移；捏合上下拖 = 缩放（上放大、下缩小）。
  左手先收一下再张开、保持 0.6 秒 = 返回上一级；
  在中国这一层再做一次返回 = 退回地球。
  （必须“先收再张”，否则左手一直摊着，一进省就会被弹回全国。）
  进图那一刻的“双手捏合”不算数：右手要先松开一次才能开始蓄力，
  左手要先真正收一次才能武装返回——否则进图后一松手就会被弹回地球。

键盘：
  M = 地球 / 地图切换；B / Backspace = 返回上一级（在中国层则回地球）；
  R = 复位；+ / - = 缩放；方向键 = 平移；
  ESC 在地图里退回地球，在地球退出程序。

纯地图入口：py -3.12 projects/hand_3d/main.py --map（直接进入地图，ESC 先回地球）。
原来独立的 projects/china_roam 已并入本目录，目录本身移到了 _archive/（不进仓库）。

文件
----------------------------------------------------------------
main.py              PyQt6 + OpenGL 渲染、模式机、手势到动作的映射

map_view.py          2D 地图视图：相机推拉、边界渲染、悬停命中、HUD
map_data.py          2D 地图数据层：GeoJSON → 墨卡托 → QPainterPath
assets/geo/          34 个省级边界文件 + manifest（33 省有下级，共 475 个市级要素）
tools/build_geo.py   重新下载边界数据
tools_check_roam.py  合并链路自检（不需摄像头）：地球→中国→广东→中国→地球
tools/test_gestures.py  地图手势自检（合成关键点）：进省 / 返回 / 缩放 / 平移 / 进图交接
detector.py          检测器：gesture_core.HandTracker 的薄封装（双手 / 480x360 / 镜像）
rules.py             转出 gesture_core 的捏合度、张开程度、掌心横坐标
geo.py               经纬度 ↔ 球面方向 ↔ 视图旋转的换算（见下）
globe_preview.png    初始姿态的离屏渲染图，可直接对照
map_preview.png      旧版球面贴片的效果图（历史参考，主路径已不走这张图）
tools_preview_globe.py    离屏渲染任意视角，调针和视角用
tools_calibrate_tex.py    贴图坐标标定（R 存列号、G 存行号，反读 s/t）
tools_verify_mapping.py   逐像素验证经纬度换算（当前色差 2.15/255）
tools_check_patch.py      验证地图贴片是否真的粘在球上（四个朝向的差分统计）
roam_country.png / roam_province.png   自检时抓的 2D 地图实测图
main_pre_roam.py.bak      合并前的 main.py 备份

2D 地图的数据、视图、手势控制器全部在本目录（assets/geo、map_data、map_view、roam），
不依赖任何其它 project；边界数据缺失时程序仍能起，只是地图模式不可用（会给出提示）。

贴图：earth 相关在根目录 textures/（day4k、clouds、lights），
      中国地图在本目录 textures/china_map.png（由 tools_make_china.py 从
      china.json 生成，等距圆柱投影，覆盖 73–135°E / 18–53.5°N）。

旧版球面贴片（遗留代码，只有单独用 GLWidget 时才看得到）
----------------------------------------------------------------
主窗口现在走 2D 地图，下面这段描述的是 GLWidget 里仍然保留的贴片实现：
改它不会影响现在的界面，留着是因为 tools_check_patch / tools_preview_globe
还在拿它做“经纬度贴到球面上”的验证。
main.py 的 _build_china_patch() 按经纬度把贴图铺成一张 96x64 的球面网格，
半径 1.004（略高于地表，避免 z-fighting），编译成显示列表：
  · 顶点在物体坐标系里，所以跟着地球一起转，转到背面就被地球挡住；
  · 纹理坐标按经纬度线性映射，1:1 时与球面上的中国严丝合缝；
  · MAP_SCALE 以中国中心为原点等比放大图片内容（不是只撑边框），
    1.15 就是整体放大 15%，会往外溢出到邻国一点。
改完跑 py -3.12 projects/hand_3d/tools_check_patch.py 验证：它分别以四个
朝向渲染“画/不画贴片”两帧做逐像素差分，正对应该大面积可见且居中、
45° 跟着往侧面走、90° 几乎看不见、180° 为 0 像素。

两个踩过的坑（都在上面那套验证里暴露过）：
  · load_texture 做过 cv2.flip(img, 0)，纹理坐标 t=0 是原图底边（南），
    给上下方向配反了整张图南北颠倒；
  · 贴片块里如果 glEnable(GL_LIGHTING) 或 glDisable(GL_BLEND) 之后不还原，
    紧接着的云层会以不透明纯白铺满整个球（原代码是隐式依赖混合一直开着的）。

经纬度是怎么摆到球面上的
----------------------------------------------------------------
GLU 的球体**北极在 +Z 轴**，不是常见的 +Y 轴。这一点搞错，任何按经纬度
放的物体都会跑到别的半球——之前大头针漂在太平洋上就是这个原因，另外它的
旋转轴还被写成了正确值的相反数，针杆其实扎进了地球内部。

当前公式（实测标定，不是猜的）：
    方向 = ( sin(经度)·sinφ,  -cos(经度)·sinφ,  cosφ )
    φ = 90° - 纬度

初始姿态用三根轴拼成旋转矩阵，保证“中国正对镜头、屏幕右=东、屏幕上=北”：
    east  = 经度增加方向
    north = 方向 × east
    dir   = 中国中心的法线
只靠 rot_x / rot_y 两个角度是做不到的——两个自由度能对准位置，但控制不了
画面旋转，所以旧版的中国是横躺着的。

改针的位置只改 geo.py 里的 PIN_LAT / PIN_LON；改初始朝向改 CHINA_LAT / CHINA_LON。
改完跑一次 py -3.12 projects/hand_3d/tools_preview_globe.py --from-main，
看本目录生成的图确认，再跑 py -3.12 tests/test_globe_modes.py 验证模式逻辑。

可调参数（main.py 顶部）
----------------------------------------------------------------
CAM_DIST_MIN / CAM_DIST_MAX  缩放范围，改小能贴得更近
PINCH_THRESHOLD              捏合判定阈值，误触多调大
ZOOM_SPEED                   缩放快慢
BASE_ROT_GAIN                旋转跟手度
MODE_SWITCH_COOLDOWN         两次地图切换的最小间隔（秒）
MAP_FADE                     地图淡入淡出速度
MAP_SCALE                    中国地图贴片的等比放大倍数，1.0=与疆域严丝合缝
CHINA_PATCH_NX / NY          贴片网格密度，改大更贴合球面但启动慢一点
POLE_GUARD_DEG               视角贴到北极多少度以内时拒绝继续上翻

可调参数（roam.py 顶部）
----------------------------------------------------------------
PINCH_THRESHOLD    捏合判定阈值，和地球模式共用同一个数
DRILL_HOLD         悬停 + 捏合多久进省（秒）
BACK_HOLD          左手“收 → 张”保持多久返回（秒）
DRAG_ZOOM          左手捏合上下拖的缩放灵敏度（每像素的对数缩放）
CURSOR_EMA         光标平滑系数，抖就调小、拖就调大
