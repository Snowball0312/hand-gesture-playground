隔空鼠标 · 说明
================================================================

界面预览：preview.png（由 tools/make_screenshots.py 离屏渲染；
背景为合成的暗色渐变，骨架由真实的 draw_skeleton 画出）

运行：双击根目录“启动隔空鼠标.bat”
依赖：py -3.12 -m pip install pyautogui

手势
----------------------------------------------------------------
张开手掌          → 移动光标
拇指 + 食指捏合    → 单击（边沿触发，捏住不放不会连点）
握拳              → 按住左键拖拽，松拳即放开
食指 + 中指伸直    → 上下移动滚动页面
其他姿态          → 不动

窗口里 ESC 退出；直接关窗口也会正常收尾。

文件
----------------------------------------------------------------
air_mouse.py       主程序：手势到鼠标动作的映射、光标平滑、窗口预览
识别与几何判定全部来自 gesture_core，本文件不含 mediapipe 代码

可调参数（air_mouse.py 顶部）
----------------------------------------------------------------
ALPHA             光标平滑系数，抖就调小，延迟就调大
ROI_X / ROI_Y     画面中央放大的有效区域，边缘留空防手出画
SCROLL_SENS       滚动灵敏度，数值越小滚得越快
SCROLL_DEADZONE   滚动死区，手微抖不触发
PINCH_THRESHOLD   捏合判定阈值，0.28；误触多调大

注意
----------------------------------------------------------------
· 这是唯一会真正接管系统鼠标的应用，第一次试把手放低一点再张掌。
· 采集用 960x540，比其它应用吃 CPU，卡的话在 HandTracker 参数里降到 640x480。
· pyautogui 的 FAILSAFE 已关闭（手快速甩到屏幕角不会中断），
  想恢复“甩到左上角急停”的保护，把 FAILSAFE 改回 True。
